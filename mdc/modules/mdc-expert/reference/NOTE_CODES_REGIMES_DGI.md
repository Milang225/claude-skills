# NOTE — Codes régimes fiscaux sur la fiche R2 (liasse DGI CI)
> Capitalisé depuis l'ex-skill `mon-comptable` (cas FAMILLE KRA SARL, NCC 2229049M, ex. 2024).

## Mapping des codes régime (fiche R2)
| Code | Régime | Statut |
|---|---|---|
| 1 | RE / Entreprenant (TCE/TEE) | actuel |
| 2 | RME / IME (microentreprise) | actuel |
| 3 | **RSI** (réel simplifié) dans la nomenclature actuelle | ⚠️ correspondait à l'ANCIEN « régime synthétique » **OBSOLÈTE** (supprimé du CGI) |
| 4 | RNI (réel normal) | actuel |

**Piège d'audit** : une liasse portant « régime code 3 » peut renvoyer à l'ancien **régime synthétique** (qui n'existe plus). Reclasser selon le CA TTC réel : RSI = ]200 M – 500 M], etc. (cf. SKILL §20.1). Cas FAMILLE KRA : CA 17,2 M → en réalité régime Entreprenant/IME, pas « synthétique ».

## Méthode « matrice d'anomalies » (déjà couverte SKILL §12-14)
Le cas FAMILLE KRA illustre la matrice P-/A-/R-/T-/N- (confusion résultat↔capitaux, stocks incohérents, trésorerie non réconciliée, immo/amortissements absents) + volet social (CNPS ZG=0). Voir SKILL §12.5 (16 tests) et §14 (audit contradictoire).
