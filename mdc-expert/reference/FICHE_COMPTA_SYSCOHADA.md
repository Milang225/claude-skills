# FICHE DE DOCTRINE — COMPTABILITÉ FINANCIÈRE SYSCOHADA RÉVISÉ
**Source :** Doumbia Diakariya, *Comptabilité Financière — Cours et sujets d'examens*, éd. 2024 NEI-CEDA, SYSCOHADA révisé (AUDCIF, en vigueur 01/01/2018 comptes personnels, 01/01/2019 consolidés/IFRS). Couverture : p.13 à p.502 (36 chapitres + opérations spécifiques + traitement de 53 opérations + principes 9+1 + exercices).
**Convention :** écritures notées `D xxxx / C yyyy` ; tous les n° de comptes sont à 4 chiffres (PCGO). Référentiel fiscal = Côte d'Ivoire / CGI 2024, TVA 18 %.

## 1. CADRE CONCEPTUEL & ORGANISATION (p.13-19, 355-357)

**Référentiel :** Système Comptable OHADA (AUDCIF adopté 26/01/2017). S'applique à toutes les entités SAUF banques, assurances, organismes de prévoyance sociale, associations. Approche mixte (déductive puis inductive). Entrée en vigueur : comptes personnels 2018, consolidés/combinés/IFRS 2019.

**Deux systèmes** (3 → 2 à la révision) :
- **Système Normal (SN)** : Bilan + Compte de Résultat (en cascade, SIG) + Tableau des Flux de Trésorerie (TFT) + Notes annexes.
- **Système Minimal de Trésorerie (SMT)** : Bilan + Compte de Résultat + Notes annexes (pas de TFT). Éligibilité (art.13, CA HT annuel <) : **négoce 60 M**, **artisanat 40 M**, **services 30 M** FCFA.

**Organisation comptable :** langue et monnaie officielles ; partie double ; pièces datées conservées **10 ans** ; enregistrement chronologique ; livres obligatoires (livre-journal, grand-livre, balance, livre d'inventaire) ; états financiers arrêtés **dans les 4 mois** suivant le 31/12.

**Codification décimale :** 1er chiffre = classe ; 2 chiffres = compte principal ; 3 = divisionnaire ; 4 = sous-compte. Constantes : **9 en 3e/4e position = solde inversé** (ex. 409 fourn. débiteur) ; **8 en 2e position = amortissement** (28) ; **9 en 2e position = dépréciation/provision** (29, 39, 49, 59, 19).
- Classes bilan 1-5 : 1 ressources durables (10 capital, 11 réserves, 16 emprunt) ; 2 actif immobilisé ; 3 stocks ; 4 tiers ; 5 trésorerie.
- Classes gestion 6,7,8 : 6 charges AO, 7 produits AO, 8 charges/produits HAO. Classe 9 = compta analytique + engagements hors bilan.

**Règles d'évaluation :** coût historique (valeur d'entrée) ; valeur actuelle (à la clôture, fonction marché + utilité, art.42) ; **VNC = min(valeur d'entrée ; valeur actuelle)** par prudence.
**Comptabilisation d'un élément** si 2 critères simultanés : avantage économique futur probable + coût/valeur évaluable de façon fiable. « Décomptabilisation » réservée aux postes de bilan.

**Définitions clés :** Actif = ressource éco. contrôlée du fait d'évènements passés. Passif externe (dette) = obligation actuelle de transférer une ressource éco. Capitaux propres = ressources mises/laissées par les propriétaires. Charges = emplois définitifs/consommations décaissés ou à décaisser. Produits = sommes reçues/à recevoir.

**Structure bilan (fonctionnelle, 3 masses chaque côté) :**
- Actif : Actif Immobilisé / Actif Circulant (stocks + créances + actif circ. HAO) / Trésorerie-Actif.
- Passif : Ressources Stables (Capitaux Propres + Dettes Financières) / Passif Circulant / Trésorerie-Passif.
- **FR = Capitaux stables − Actif immobilisé** ; **BFE = Actif circulant − Passif circulant** ; **Trésorerie = FR − BFE**.

### Les 9 + 1 Principes comptables (p.355-357)
**Postulats :** (1) Entité ; (2) Comptabilité d'engagement ; (3) Spécialisation/indépendance des exercices (art.59) ; (4) Permanence des méthodes (art.9,10,40) ; (5) **Prééminence de la réalité économique sur l'apparence juridique** — application LIMITÉE à 4 cas (« le +1 ») : a) crédit-bail/location-vente à l'actif du preneur (compte 17 au passif) ; b) biens avec clause de réserve de propriété à l'actif de l'acheteur ; c) personnel facturé (gardiennage) en charges de personnel ; d) effets escomptés non échus maintenus à l'actif.
**Conventions :** coût historique/nominalisme monétaire (art.35,36) ; prudence (art.3,6) ; transparence/non-compensation (art.6,8,10,11,14,34) ; intangibilité du bilan (bilan clôture N = ouverture N+1, art.34) ; importance significative (art.33, seuil 5 % pour créances non courantes).
**Correction d'erreurs (art.20) :** inscription en **négatif** des éléments erronés, puis enregistrement exact. Erreur antérieure significative → ajuster le **report à nouveau (12)** ; non significative → comptes de bilan/résultat AO.

## 2. ACHATS / VENTES — FACTURATION (Ch.10, p.63-90)

**Facture normalisée (CI)** obligatoire (sticker sécurité, NCC, régime). Exceptions : CIE/SODECI/téléphone, ventes au détail à tickets, pharmacies, compagnies aériennes, pétroliers contrats de partage, stations carburant, Poste CI, banques.

**Réductions :**
- Commerciales (remise, rabais, ristourne) : calculées **en cascade** ; le **dernier net commercial** alimente 601/701.
- Financière (escompte) : produit financier, n'affecte pas le coût du stock.
- Hors facture : remise/rabais réputés **nets de TVA**.

**Comptes :** 601 Achats m/ses, 6015 frais sur achats ; 602/6025 matières ; 604/6045 fournitures ; 6081 emball. perdus / 6082 emball. récup. non identif. / 6085 frais ; 701 ventes m/ses, 702 produits, 706 services, 7071 port et frais facturés, 707 produits accessoires. RRR : obtenus 6019/6029/6049/6059/6089 ; accordés 7019/7029/7059/7069. Escompte : **673** accordé (charge fin.), **773** obtenu (produit fin.). TVA : 4431 facturée/ventes, 4432 fact./prestation, 4452 récup./achats, 4451 récup./immo, 4453 récup./transport, 4454 récup./services.

**Écriture-type facture DOIT (avec remise, escompte, TVA, port) — chez le client :**
```
D 6011  Achats de marchandises (dernier net commercial)
D 6015  Frais sur achat (port récupéré)
D 4452  TVA récupérable sur achat
   C 401  Fournisseur (net à payer)
   C 773  Escompte obtenu
```
**Chez le fournisseur :**
```
D 411  Client (NAP)        D 673 Escompte accordé
   C 701  Ventes de marchandises
   C 4431 TVA facturée sur vente
   C 7071 Port et autres frais facturés
```

**Transport :** assuré par le fournisseur → 7071 (vente) / 6015 (achat). Transport par tiers « port payé/avancé » → expédition d'abord (613 Transport pour compte de tiers + 4453), puis facture client. **Transport public** soumis à TVA seulement si entreprise au régime réel (CA TTC > 200 M).

**Avoir (retour/réduction hors facture) :** écriture inverse (retour de m/ses), ou 7019/6019 (ristourne hors facture, nette de TVA).

**Acompte sur commande :** chez client `D 4091 / C 571` ; chez fournisseur `D 571 / C 4191`. À la facturation, l'avance est déduite du NAP et le 4091/4191 soldé. (4191 client av. reçues, 4091 fourn. av. versées ; 25/252 si immo.)

**Escompte conditionné (règlement sous escompte) :** régulariser la TVA sur escompte effectivement obtenu. Ex. montant réglé 1 132 800 sous escompte 4 % → NAP 1 180 000, escompte TTC 47 200 (HT 40 000, TVA 7 200 à régulariser).

**Documents à NE PAS enregistrer :** devis, proforma, relevés de factures, bons (commande/livraison/réception), bordereaux de versement.
**TVA non déductible (art.372 CGI) :** mobilier, véhicule tourisme > 12 CV, frais hôtel/restaurant/représentation, carburant véhicules, entretien de biens exclus, achat > 250 000 réglé **en espèces**. Déductible : véhicules utilitaires, tourisme ≤ 12 CV, 2 roues ≤ 3 M HT, matériels de manutention, véhicules de location/transport public.

## 3. EMBALLAGES (Ch.11, p.91-96)

Catégories : immobilisés/matériel d'emballage (243, identifiables, citernes) ; commerciaux perdus (6081) ; récupérables non identifiables (6082, consignés).
**Consignation faite TTC** : dette fournisseur / créance client.
```
Consignation chez fournisseur : C 4194 Clients, emballages consignés (TTC)
Consignation chez client      : D 4094 Fournisseur, emballages à rendre (TTC)
```
**Déconsignation (prix repris = prix consigné) :** écriture inverse.
**Non-restitution (vente d'emballage) :** fournisseur `D 4194 / C 7074 Boni + C 4431` ; client `D 6224 Malis (ou 6082) + D 4452 / C 4094`.
**Reprise à prix < consignation :** différence = **boni** (fournisseur, 7074) / **mali** (client, 6224), TVA sur la différence.
**Stock d'emballages :** compte 387 (3871 en consignation, 3872 en dépôt). Fiche de stock = seulement emballages propriété de l'entité.

## 4. IMMOBILISATIONS — ACQUISITION (Ch.10 §IV + Ch.28, p.74-90, 291)

**Coût d'acquisition HT** = prix d'achat net de remises/rabais/escompte et taxes récupérables + frais directement liés (droits de mutation, douane, transit, transport, installation, montage, manutention nécessaires à la mise en service, honoraires, commissions, frais d'actes) + TVA non récupérable + estimation initiale du coût de démantèlement/remise en état (art.37). **Exclus :** formation, maintenance, frais administratifs, charges en aval, différences de paiement, sous-activité, pertes initiales.
**Coûts d'emprunt** incorporables seulement pour un **actif qualifié** (préparation ≥ 12 mois). Escompte sur immobilisation : vient **en diminution du prix** (pas de 773).

**Écriture acquisition locale :**
```
D 2xxx  (241 mat. & outillage, 2411 mat. industriel, 2442 mat. informatique, 2444 mobilier, 245/2451 mat. transport)
D 4451  TVA récupérable sur immobilisation
   C 481/4812  Fournisseur d'investissement (TTC ou TVA non déd. incluse)
```
TVA **non déductible** sur mobilier de bureau (2444) et véhicule tourisme > 12 CV → entrent en TTC. Pour entreprise de location/transport, l'acquisition de véhicules est courante → crédit **404/4042** (et non 481).

**Importation :** prix converti au cours du jour, + droits de douane (crédit **4426** État, droits de douane, si dus directement), + transit, montage. Prorata de déduction → quote-part TVA non déductible incorporée au coût.

**Livraison à soi-même (LASM) / Production immobilisée** = coût de production (matières + charges directes) :
```
D 21../24..  Immobilisation
D 4451       TVA récupérable sur immobilisation
   C 721/722  Production immobilisée (incorporelle/corporelle)
   C 4434     TVA facturée sur production livrée à soi-même
   (C 787 Transfert charges financières si coûts d'emprunt incorporés ; 24x1 « en cours » si non achevé)
```
TVA sur bâtiment affecté au **logement du personnel** non déductible.

**Approche par composants (art.38-1) :** chaque élément à usage/rythme différent dans un sous-compte + plan d'amortissement propre (ex. structure bateau 24531 / moteur 24532). Au renouvellement : sortie de l'ancien composant (`D 28xx + D 812 VCN / C 24xx`), entrée du nouveau.
**Frais d'inspection/révisions majeures (Ch.26, art.38-2) :** composant distinct amorti sur la durée jusqu'à la prochaine inspection ; au remplacement, sortie de l'ancien composant (totalement ou partiellement amorti via 812). **Aucune provision pour grosses réparations admise.**

## 5. AMORTISSEMENTS (Ch.17, p.179-198)

**Définition :** répartition systématique du montant amortissable sur la durée d'utilité. **Base amortissable = Valeur d'origine − Valeur résiduelle** (art.45). VNC = VO − Σ amortissements. Taux = 100/durée (an) ou 1200/durée (mois). Révision annuelle de la valeur résiduelle et de la durée (changement d'estimation, art.45).

**Durées/taux fiscaux usuels (CI) :** construction comm. 20 ans/5 % ; matériel transport 3 ans/33,33 % ; matériel & outillage 5 ans/20 % ; mobilier/matériel bureau 10 ans/10 % ; agencements 10 ans/10 % ; matériel informatique 2 ans/50 %. (Frais d'établissement : maintenus en charges par nature.)

### Modes
| Mode | Formule annuité |
|---|---|
| Linéaire | VO × t (prorata temporis : ×n/12 mois ou ×n/360 jours) |
| Dégressif fiscal | VNF début période × taux dégressif ; **taux dégr. = taux linéaire × coeff.** ; coeff. **1,5** (3-4 ans), **2** (5-6 ans), **2,5** (>6 ans). Bascule linéaire quand 100/(années restantes) ≥ taux dégressif (annuités = VNF/années restantes). Nb d'années linéaires ≈ partie entière de (durée/coeff.) |
| Dégressif à taux décroissant (SOFTY) | taux = (années restant à courir)/(Σ n° d'ordre, ex. 8 ans → 36) ; base = VO constante |
| Accéléré (fiscal) | 1re annuité linéaire **doublée** (mat. & outillage neufs, usage industriel, durée > 5 ans) |
| Unités d'œuvre / production | base amort. × (UO consommées / UO totales prévues) ; **pas de prorata temporis**, pas d'amort. dérogatoire |

**Comptabilisation amortissement économique :**
```
D 681 (6813 immo corp / 6812 immo incorp)  Dotation aux amortissements d'exploitation
   C 28xx  Amortissement de... (8 intercalé en 2e position : 2841, 28411, 2812...)
```
**Amortissements dérogatoires** (excédent fiscal du dégressif/accéléré sur le linéaire) = provisions réglementées :
```
Constitution : D 681 (annuité linéaire) C 28xx | D 851 (excédent) C 151 Amortissement dérogatoire
Reprise (quand annuité fiscale < linéaire) : D 151 C 861 Reprise de provisions réglementées
```
**Amortissement HAO** (restructuration, changement d'affectation, catastrophe) : compte **852**.
**Immeuble affecté au personnel** (art.6 III C) : amort. accéléré exceptionnel de **40 %** du prix de revient (logement 3 pièces ≤ 4,5 M) au 1er exercice après achèvement.

## 6. CESSIONS / VOL / ÉCHANGE D'IMMOBILISATIONS (Ch.17 §III, p.189-194)

Cession = vente, destruction, vol, disparition. Distinguer **occasionnelle** (81/82) et **courante** (654/754, sociétés de leasing/transport). **Pas de compte de +/− value** : le résultat ressort du solde 81/82, soldés en fin d'exercice par le **13 Résultat**.

**Cession occasionnelle (3 écritures + dotation complémentaire) :**
```
1) D 485 (ou 521) C 822 Produit de cession immo. corp. [+ C 4431 si TVA due]
2) D 6813 C 28xx  (amortissement complémentaire du 01/01 à la date de cession)
3) D 812 V.C. cession + D 28xx Amort. cumulé  /  C 2xx Immobilisation (sortie pour VO)
```
Résultat de cession = Prix cession − VNC (le solde du 812 = VNC). Indemnité d'assurance (bien détruit) = prix de cession.
**Cession courante :** 754 (produit), 654 (VCN).
**TVA :** la D.G.I. impose le prix de cession d'une immo. dont la TVA fut déduite (D 822 ... C 4431). Si TVA non déduite à l'origine (non assujetti / bien exclu / occasion) → hors champ, pas de régularisation.
**Vol/destruction/perte :** **reverser la TVA** = TVA initialement déduite × (VNC/VO) = TVA × (années restantes / durée totale). `D 241 C 4441` puis sortie sur (VO + TVA reversée). Résultat = Prix − (VNC + TVA reversée).
**Échange :** comptabiliser **séparément** la cession de l'ancien et l'acquisition du nouveau (recommandation SYSCOHADA).
**Cession avec plus-value à réinvestir** (exonération si réemploi sous 3 ans, art.8 CGI) : `D 851 / C 152 Plus value à réinvestir`. Reprise progressive `D 152 / C 861` au taux d'amortissement du nouveau bien (ou en totalité si non réinvesti). **Montant min. à réinvestir = Σ amort. du bien cédé + prix de cession = VO + plus-value.**

## 7. PROVISIONS & DÉPRÉCIATIONS (Ch.18, p.199-216)

**Provision** = passif externe à échéance/montant incertain (risque > 1 an). **Dépréciation** = perte de valeur d'un actif (≠ provision). Critères de provision : obligation actuelle (fait générateur passé) + sortie de ressources probable + montant fiable estimable. Sinon → **passif éventuel** (notes annexes).

**Comptes de provisions pour R&C :** 191 litiges, 192 garanties clients, 193 perte sur marchés à achèvement, 194 perte de change, 195 impôts, 1961 pensions/retraite, 197 restructuration, 1981 amendes/pénalités, 1984 démantèlement, 499 risques CT exploitation, 599 risques CT financiers, 151 provisions réglementées.

**Schéma dotations/reprises :**
| Nature | Dotation | Reprise |
|---|---|---|
| R&C exploitation LT | D 6911 / C 19 | D 19 / C 7911 |
| R&C financières LT | D 6971 / C 19 | D 19 / C 7971 |
| R&C HAO | D 854 / C 19 | D 19 / C 864 |
| R&C exploit. CT | D 6591 / C 499 | D 499 / C 7591 |
| R&C financières CT | D 6791 / C 599 | D 599 / C 7791 |
| Dépréc. stocks | D 6593 / C 39 | D 39 / C 7593 |
| Dépréc. créances clients | D 6594 / C 4912 | D 4912 / C 7594 |
| Dépréc. titres placement | D 6795 / C 590-3 | D 590-3 / C 7795 |
| Dépréc. immo. incorp. | D 6913 / C 291 | D 291 / C 7913 |
| Dépréc. immo. corp. | D 6914 / C 294 | D 294 / C 7914 |
| Dépréc. immo. financières | D 6972 / C 296,297 | D / C 7972 |

**Provisions réglementées (151,152, plus-values, dérogatoires) :** dotation 851, reprise 861.

**Test de dépréciation d'immobilisation :** si indice de perte de valeur, comparer **valeur actuelle** (= valeur recouvrable = max(valeur vénale/marché ; valeur d'usage = flux futurs actualisés)) à la VNC. Si VA < VNC → dotation 6913/6914. La VA devient la nouvelle base amortissable sur la durée restante. Reprise plafonnée à la VNC qui aurait existé sans dépréciation.

**Règle de réajustement (à retenir) :** +value sans provision antérieure → RAS ; +value avec provision → reprise. −value sans provision → dotation ; avec provision : si ancienne > nécessaire → reprise différence ; si < → dotation différence.

**Créances douteuses :** dépréciation calculée sur le montant (TTC en CI, la TVA collectée n'étant pas remboursée). Transfert `D 416 Clients douteux / C 411`. Perte définitive `D 651 (ou 6511) / C 416 ou 411` + reprise de la dépréciation devenue sans objet (D 4912/C 7594). Recouvrement d'une créance soldée : `D 521 / C 758 (ou 751)`. Créance HAO (485) → perte au 834.
**Titres de placement (50) :** acquis au coût d'achat (frais en 5016/5026/5036). Cession : différence prix cession/prix achat → 677 (perte) ou 777 (gain) ; reprise de dépréciation antérieure.

## 8. VALORISATION DES STOCKS (Ch.19, p.217-220) + INVENTAIRE (Ch.8, p.49-53)

**3 méthodes SYSCOHADA :** PEPS/FIFO (épuisement des lots) ; **CMP après chaque entrée** (inventaire permanent) ; **CMP sur durée moyenne de stockage** (inventaire intermittent). LIFO interdit.
- **CMP après entrée** = (valeur stock restant + valeur entrée) / quantité totale.
- **Durée moyenne de stockage** = (Stock moyen × période) / total sorties ; Stock moyen = (SI+SF)/2 ; ou durée = 12 / taux de rotation (taux = sorties/stock moyen). Stock final valorisé au CMP des entrées de la période moyenne de stockage.

**Inventaire intermittent (comptes de variation 6031 m/ses, 6032 matières, 736 produits) :**
```
Annulation SI : D 6031 / C 31 (stock initial)
Constitution SF : D 31 / C 6031 (stock final)
```
SI > SF → déstockage (charge) ; SI < SF → stockage (produit). 603/6031 (achats), 736/73 (production).
**Inventaire permanent :** comptes de stock mouvementés en continu ; en fin d'exercice comparer **stock théorique** (solde du compte) au **stock réel (physique)** : si théorique > réel `D 603 / C 31` ; si théorique < réel `D 31 / C 603`.
**Dépréciation de stock** (inventaire intermittent) : annuler dépréciation initiale (D 39/C 7593) puis constituer la finale (D 6593/C 39).

## 9. TVA, AIRSI, PRORATA (Ch.13, p.109-122)

**TVA** : impôt indirect neutre. **Fait générateur** : livraison (biens), encaissement (services), facturation (télécom prepaid), mise à consommation (importations). Taux : **18 %** (15,25 % sur TTC) ; 9 % (pâtes semoule blé, lait, énergie solaire) ; 5 % (micro-assurance). T.O.B. 9,09 % TTC / 10 % HT (agios bancaires, déductible).
**Mécanisme :** TVA due = TVA exigible (collectée) − TVA déductible. Si négatif → **crédit de TVA reporté** (4449).
**Écriture déclaration mensuelle :**
```
D 4431 TVA facturée sur vente
D 4432 TVA facturée sur prestation
   C 4451/4452/4454 TVA récupérables (immo/achats/services)
   C 4441 État, TVA due  [ou D 4449 Crédit de TVA si déductible > exigible]
Règlement : D 4441 / C 4449 (crédit antérieur imputé) / C 521 (solde)
```
Sous-comptes par période 01-12 (mensuel) ou 01-04 (trimestriel) en 5e/6e position.
**Remboursement crédit TVA** (délai 3 ans) : exportateurs, cessations, investissements industriels, crédit-bail, biens d'investissement > 40 M TTC.

**Prorata de déduction (assujetti partiel) :** **Prorata = (CA taxable + assimilés) / CA total × 100**. Numérateur : CA TVA + exportations + exonéré conventionnel + LASM taxable HT. Dénominateur : numérateur + CA exonéré + hors champ + LASM exonérée. **Exclus du calcul** : cessions d'actif, produits financiers, remboursements de frais, dommages-intérêts, subventions d'équipement, primes export. Prorata **provisoire** (de N-1) appliqué en N, régularisé en fin N (prorata définitif) : si définitif > provisoire → complément de déduction ; si < → reversement. TVA déductible = TVA récupérable × prorata.

**AIRSI** (Acompte d'Impôt sur le Revenu du Secteur Informel, 5 % du droit commun ; 2 % / 1,5 % / 0,2 % particuliers) : prélevé par les entreprises au réel sur ventes aux entreprises **hors régime réel** (entreprenant, micro-entreprises). Exclus : ventes au réel, aux ménages, à l'État, exportées, prestations de services, eau/élec/gaz/pétroliers. Chez le vendeur : `C 4492 État, avances et acomptes versés sur impôts`. Chez l'acheteur (hors réel) : non comptabilisé séparément, inclus dans la charge.

## 10. RÈGLEMENTS, EFFETS DE COMMERCE, RAPPROCHEMENT (Ch.14-15, p.125-142)

**Chèques reçus :** 513 chèque à encaisser → 514 chèque à l'encaissement → 521 (avis crédit, − 631 frais + 4454). Chèque impayé : `D 6318 + D 4131 Client chèque impayé / C 521 / C 7078`.
**Monnaie électronique :** 55 instrument de monnaie électronique, 6317 frais.

**Effets de commerce** (lettre de change / billet à ordre) :
```
Tirage (fournisseur)   : D 4121 Client, effets à recevoir / C 4111 Client
Acceptation (client)   : D 4011 Fournisseur / C 4021 Fournisseur, effets à payer
(Immo : 146/147 effets à recevoir ; 4046/4047, 4811/4812, 4821/4822 effets à payer)

```

### 15.3 Opérations en monnaies étrangères (Ch.24, p.271-277)

Diminution dette / augmentation créance → **479 Écart de conversion-Passif** (gain latent, non comptabilisé, prudence).
**Étalement (art.56)** : pertes/gains sur emprunts/prêts pluri-exercices étalés sur la durée restant à courir (provision = perte × fraction écoulée). Contrepassation des écarts et intérêts courus à l'ouverture.

### 15.11 Coût de démantèlement / remise en état (Ch.34, p.317-319)

### 15.12 Engagements de retraite (Ch.36, p.333-338)

Indemnité future = salaire fin de carrière × (ancienneté actuelle/totale). Variation = coût des services rendus + coût financier (engagement × taux). Écart actuariel (changement d'hypothèse) en 6911/6971 (perte) ou 7911/7971 (gain). Provision **1961 Provisions pour pensions**. Au départ : reprise de provision (79) + `D 6618 / C 422 + 44 + 521`.

## 16. SYSTÈMES & JOURNAUX (Ch.5-9, 12, p.41-108)

- **Virement** : transfert débit→débit ou crédit→crédit (regroupement/ventilation). Comptes virements internes : **585** virements de fonds, **588** autres.
- **Réciprocité** : deux comptes réciproques (banque/entité) ont soldes identiques opposés.
- **Partie double** : Σ débits = Σ crédits. Actif : ↑ débit, solde débiteur. Passif : ↑ crédit, solde créditeur.
- **Balance** : liste verticale des comptes, contrôle de la partie double. Tracés à 6 colonnes (soldes ouverture / mouvements / soldes clôture) ou 8 colonnes (+ variations).
- **Système classique** (journal unique) / **système centralisateur** : journaux auxiliaires (achats, ventes, caisse, banque, effets, OD) → journal centralisateur → grand-livre → balance. Grand-livre auxiliaire (clients/fournisseurs), relevés nominatifs. Vente/achat au comptant : transiter par les comptes de tiers.
