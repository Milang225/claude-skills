12-week plan (started 2026-10-08). Month 1 Fondations: S1 présent simple/continu, S2 prétérit + past continuous + irréguliers, S3 futurs + questions, S4 present perfect vs prétérit. Month 2 Fluidité: S5 PP continu + past perfect, S6 modaux, S7 conditionnels, S8 passif + used to. Month 3 Autonomie: S9 discours indirect + phrasal verbs, S10 relatives/comparatifs/articles, S11 connecteurs + anglais pro, S12 révision + oral 5 min.

Artifact https://claude.ai/artifact/ChhwLiFvnExfG3fG7JmuJz (source `cours-anglais.html`, capability sample) has tabs: Aujourd'hui, Les fondamentaux (10 briques + décodeur + quiz; articles brique 2 réexpliquée simplement), Vocabulaire de base (435 mots, 17 thèmes, mots connus en localStorage, quiz), Les temps en français (rappel grammaire FR + correspondance FR→EN), Les auxiliaires, Verbes réguliers (105 verbes, règles -ed, sons), Les adverbes (formation, types, place, pièges, 2 exercices), Les prépositions (schémas lieu, mouvement, temps, à/de, verbe+prép, pièges, 26 questions), Les pronoms relatifs (who/which/that/whose/where/when/what, omission, virgules, dont/ce que, 3 exercices; helper mcqSet()), Phrasal verbs (80 verbes, particules, séparables, noms composés, idioms, quiz, explication Claude), Parler (Sam chat partner), Penser en anglais (chunks), Bien lire (stress/linking/echo + Claude analysis), Construire une phrase (word order, tiles, atelier écrit corrigé), Conjugaison (+ conjugueur), Verbes, Exercices, Lecture, Phrases, Programme.
