RÈGLE PERMANENTE : à chaque nouveau document créé (note, rapport, modèle, courrier...), en déposer une COPIE dans `~/Documents/BASE DOCUMENTAIRE LMDC` — à DEUX emplacements :
1. Le sous-dossier thématique approprié (01_ANALYSE_BANCAIRE, 02_COMPTABILITE, 03_FISCAL_EXPOSITION, 04_DECLARATIONS, 05_NOTES_CONSEIL, 06_PROCEDURES, 08_ORGANISATION_INTERNE) — comme modèle réutilisable pour les prochains cas.
2. `07_DOSSIERS_TRAITES/<nom du client>` — pour l'archive du dossier concerné.

**Why:** l'utilisateur veut pouvoir réutiliser plus tard le travail déjà produit (modèles, exemples) sans le rechercher dans les dossiers clients épars. Voir [[demarche-audit-colonne-vertebrale-et-suivi]] et [[kit-livrables-audit-mdc]].

**How to apply:** dès qu'un document final (pas un brouillon de travail) est produit pour un client ou une mission, faire les deux copies avant de considérer la tâche terminée. Ne pas attendre que ce soit demandé.
