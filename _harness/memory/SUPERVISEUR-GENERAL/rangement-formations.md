RÈGLE : chaque fois qu'une **formation** (support de cours, quiz, slides) est créée, la **ranger dans `/Users/bilefilsseverin/Documents/FORMATIONS MDC`** (le dossier formations de l'utilisateur).

**Why:** l'utilisateur centralise ses formations MDC à cet endroit ; les livrables de formation ne doivent pas rester éparpillés dans les dossiers clients.

**How to apply:** produire la formation (Word/PDF via les scripts mdc-expert), puis enregistrer/copier le(s) fichier(s) dans `Documents/FORMATIONS MDC`. On peut garder une copie dans le dossier client si la formation est liée à un cas, mais l'exemplaire de référence va dans FORMATIONS MDC. Voir [[supervision-redaction-avant-livraison]] (toujours passer par la rédaction avant diffusion).
