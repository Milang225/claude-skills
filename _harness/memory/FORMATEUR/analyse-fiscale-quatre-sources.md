**Pour toute requête fiscale, se référer aux QUATRE sources et produire une ANALYSE :**

1. **le droit comptable** — SYSCOHADA révisé, AUDCIF : comment l'opération se traduit en écritures et ce que les principes comptables imposent ;
2. **le Code général des Impôts** — l'article applicable, cité verbatim ;
3. **la Doctrine fiscale DGI** — les notes de service de portée générale ;
4. **le Bulletin officiel de la DGI** — l'analyse de l'annexe fiscale de l'année.

Consigne donnée par le gérant en septembre 2026.

**Why:** une réponse fondée sur une seule source est incomplète et souvent fausse. Le CGI donne la règle, la doctrine dit comment l'administration l'applique, le bulletin signale ce que l'annexe fiscale vient de changer, et le droit comptable détermine si le montage est seulement praticable. Un montage fiscalement défendable mais comptablement infaisable ne vaut rien — et l'inverse est vrai. C'est la valeur ajoutée attendue d'une Agence de notation : croiser, pas citer.

**How to apply:** interroger les quatre fichiers de `Documents/FORMATIONS MDC/00_TEXTES_OFFICIELS_DGI/` — voir [[textes-officiels-dgi-locaux]] — **avant** de répondre. Structurer la réponse par source, puis **conclure par une analyse** qui tranche, et non par une juxtaposition de citations. Dire nommément ce qu'aucune des quatre sources ne règle, conformément à [[questions-germees-avant-reponse]].
