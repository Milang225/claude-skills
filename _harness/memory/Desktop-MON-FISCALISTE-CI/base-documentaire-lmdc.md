Le gérant constitue sa **BASE DOCUMENTAIRE LMDC** : `Documents/BASE DOCUMENTAIRE LMDC/`.
Structure : 6 domaines — `01_ANALYSE_BANCAIRE`, `02_COMPTABILITE`, `03_FISCAL_EXPOSITION`, `04_DECLARATIONS`, `05_NOTES_CONSEIL`, `06_PROCEDURES` — + `07_DOSSIERS_TRAITES/<CLIENT>_<ANNÉE>/` (copie intégrale du dossier). Catalogue en tête : `00_CATALOGUE_BASE_DOCUMENTAIRE_LMDC.docx` (réf. MC-BASE-DOC-2026-001).

**Règle d'alimentation** (à appliquer à CHAQUE mission) : copier le dossier client complet dans `07_DOSSIERS_TRAITES/`, verser les livrables réutilisables dans le domaine correspondant, puis mettre à jour le catalogue. Premier dossier de référence versé : **LERO 2025** (20 livrables) — voir [[client-lero-forage]]. Méthodologie de ce type de mission capitalisée dans le skill mdc-expert **§31** (reconstitution multi-comptes & régularisation d'un CA dissimulé).
