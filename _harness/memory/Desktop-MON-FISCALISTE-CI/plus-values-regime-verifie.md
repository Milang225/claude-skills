Formation dédiée : `MON FISCALISTE CI/FORMATION_PLUS_VALUES_CI.md` (traitement comptable SYSCOHADA + fiscal). Articles **vérifiés sur le CGI officiel** (recueils DGI OCR-isés dans `MES DOCS FISCALITÉ`, à jour **AF 2025** ; AF 2026 = pas de changement sur ce thème).

**Articles verrouillés :**
- **Art. 14** — plus-value de cession intégralement imposable ; moins-value déductible.
- **Art. 28-1er** — exonération SI engagement de réinvestir en immobilisations en CI sous **3 ans**. ⚠️ Montant à réinvestir = **plus-value + valeur d'origine = prix de cession + cumul amortissements (le cash-flow)**, PAS le prix de cession seul. Non-remploi → réintégration (imprimé BIC, ligne 2.2 sous-ligne 08) + intérêts. Véhicule comptable = **compte 155**.
- **Art. 23** = *caractéristiques* de la holding (SA/SARL ivoirienne, 2/3 actif immo = participations statut société mère, interdite d'activité commerciale/industrielle). **Art. 29** = *régime* : **12 %** sur plus-values de titres détenus **≥ 2 ans**, **exonération** si portefeuille **≥ 60 % UEMOA** (art. 29 dernier §). → l'ancienne ambiguïté « 23 ou 29 » est levée : **les deux, complémentaires**. Le concept long/court terme n'existe QUE pour les titres des holdings.
- **Art. 22** = statut société mère → exonère les **dividendes ~95 %** (pas les plus-values).
- **Art. 110-1°** = déduction pour réinvestissement de **bénéfices** — distinct de l'art. 28.
- **Réévaluation libre = art. 330-338.** Particuliers/immeuble = **droit 17 % sur PV forfaitaire 20 % du prix (= 3,4 % effectif)** + mutation 4 % + publicité foncière 1,2 % (art. 38-3 AF 2025) ; sociétés à l'I-BIC exclues de ce droit.

**2 ERREURS du corpus corrigées (ne pas re-propager) :**
1. **Réévaluation libre** — le cours `FORMATION BILAN SN` dit « produit imposable immédiatement et en totalité » : **FAUX**. Le CGI (art. 334) : écart **exonéré d'I-BIC** (compte 1062, capitaux propres), **reprise étalée** au rythme des amortissements pour les biens amortissables → **aucune économie d'I-BIC** ; cession d'un bien réévalué = plus-value fiscale sur **valeurs non réévaluées** (art. 335) ; surcoût foncier/patente sur 100 % valeur réévaluée (art. 337).
2. **Art. 28** — le montant à réinvestir n'est pas le prix de cession (voir ci-dessus).
