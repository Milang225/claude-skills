Dans toutes les explications (fiscalité, comptabilité, douane, formations), **donner systématiquement la définition développée de chaque sigle/acronyme la première fois qu'il apparaît** — ne jamais laisser un sigle nu.

**Pourquoi** : l'utilisateur apprend/enseigne la matière et bute sur les sigles non explicités (a demandé successivement « AF c'est quoi », « TEC c'est quoi », « PCS et PC c'est quoi »).

**Comment l'appliquer** : écrire par ex. « TEC (Tarif Extérieur Commun) », « AIRSI (Acompte d'Impôt sur le Revenu du Secteur Informel) », « CAF (Coût, Assurance, Fret) ». Vaut aussi dans les livrables PDF produits pour lui. Voir [[mdc-livrables-formation-fiscale]].
