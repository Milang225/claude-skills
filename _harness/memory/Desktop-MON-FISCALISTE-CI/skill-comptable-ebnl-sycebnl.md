Le **skill `comptable-ebnl`** existe dans `~/.claude/skills/comptable-ebnl/` : comptabilité des
Entités à But Non Lucratif selon le **SYCEBNL** (Acte uniforme AUSYCEBNL, OHADA, en vigueur au
**1er janvier 2024**). Contient `SKILL.md` (mémo opérationnel : 10 réflexes, arbre de décision,
playbook d'écritures, procédure de clôture, contrôle) + 5 fiches dans `reference/` (cadre juridique,
plan des comptes classes 1‑9, 22 écritures corrigées, maquettes d'états financiers, fiscalité). C'est le
pendant EBNL du skill [[mdc-expert]] (SYSCOHADA, entités à but lucratif).

Le **support de l'atelier** (8 modules pédagogiques + présentation + index) est dans
`Desktop/MON FISCALISTE CI/ATELIER SYCEBNL - MODULES/`.

**Faits SYCEBNL clés à réutiliser :** deux familles d'EBNL (associations/fondations → Bilan + Résultat +
TFT + Notes ; projets de développement → État des dépenses et ressources + Bilan + Résultat + Notes) ;
SMT si chaque ressource ≤ 30 M FCFA ; CAC obligatoire si 2 des 3 seuils (bilan >100 M, ressources
>200 M, effectif >30) ; neutralité du résultat par reprises 79x et quotes‑parts 702/703.

**Divergence de numérotation à connaître** (plan officiel du manuel vs corrigés du guide d'application) :
reprise fonds affecté projet = **7922** (officiel) / 7925 (guide) ; contributions volontaires en nature =
**classe 96/97** (964 personnel bénévole, 974 bénévolat) / 90‑91 (guide) ; dons en nature HAO vendus =
**8411** (officiel) / 8421 (guide). Les modules retiennent le plan officiel + notes de réconciliation.
Sources : manuel officiel SYCEBNL, guide d'application (22 cas), programme de l'atelier — dans
`Desktop/MES DOCS FISCALITÉ /`. Voir aussi [[toujours-verifier-dgi-2026]] pour le volet fiscal.
