L'utilisateur veut un assistant personnel qui :
- Suit ses projets/dossiers clients (un sous-dossier par projet dans `~/Desktop/MON ASSISTANT/projets/`)
- A une vue sur ses emails Gmail (MCP gmail connecté)
- A une vue sur son WhatsApp Business (⚠️ pas de MCP installé à ce jour — à brancher plus tard)
- Fait les rappels via BusyCal (MCP BusyCal connecté)
- Organise les rencontres dans BusyCal
- Produit la to-do list consolidée à partir des `etat.md` de chaque projet

**Why:** demande initiale du 2026-04-19.
**How to apply:** à chaque interaction sur ce workspace, raisonner en terme de projets + échéances + actions ; produire briefings matin (8h) / soir (18h) via scheduled-tasks une fois la liste des projets connue.
